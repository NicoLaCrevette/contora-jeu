# CONTORA (Контора)

**Moscou, 25 décembre 1999.** Dans un sous-sol, devant un vieux PC à écran cathodique, chaque opérateur doit
gagner sa **quota** avant minuit : casinos en ligne, émissions en direct, bourse, crypto, prêts douteux…
et quelques farces aux amis. À minuit, le Comptable appelle. Qui ne paie pas devient un **Fantôme**.
Le 31 à minuit, le monde passe à l'an 2000 : le dernier debout gagne.

De 1 à 6 joueurs par Internet (un code de 4 lettres, rien à régler sur la box), ou seul contre trois robots.

## Télécharger

👉 **[Contora_Setup.exe](https://github.com/NicoLaCrevette/contora-jeu/releases/latest/download/Contora_Setup.exe)**
(Windows 10 et 11, environ 100 Mo)

Lance l'installateur, puis l'icône **Contora** sur le Bureau. Le lanceur installe tout seul chaque nouvelle
version (versions signées : il refuse tout fichier qui ne vient pas de Contora).

## À savoir

- **Aucun argent réel.** Tout est fictif, les marques sont des parodies.
- Le code du jeu n'est pas sur cette page : elle sert seulement à distribuer les versions prêtes à jouer.
